# Pitch — bendwith.us

Shan owns this script. This file currently holds one beat that is easy to lose and
expensive to lose: how the name is said out loud.

## The name, said once (≈0:45, as the patient opens the app)

> **"bendwith.us — because it bends with you."**

Say it as the URL appears on screen, then carry on into the live session.

Why it needs saying rather than just showing: written down, the pun lands on its own.
Heard cold, "bendwith dot us" is ambiguous — a judge can hear "bend with us" and never
register that the name *is* the domain. One beat fixes that, and it makes the case for
Best Domain Name (GoDaddy Registry) in the same breath as the ElevenLabs voice moment,
without spending a separate line on either.

Keep it to one pass. Repeating the pun sells it and undoes it.
